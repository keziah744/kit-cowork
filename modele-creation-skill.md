# Créer une skill avec Claude — modèle à copier-coller

**Principe** : une skill = une tâche que vous expliquez une fois à Claude, comme à un nouvel employé. Ensuite il suffit de la demander en une phrase.

Remplissez les parties entre crochets `[...]`, puis collez tout le message à Claude.

---

Je veux créer une skill Claude pour automatiser une tâche de mon domaine. Pose-moi tes questions **une par une** si quelque chose n'est pas clair, puis crée la skill et testons-la ensemble sur mon exemple.

**Nom de la tâche** : [ex. relance des factures impayées]

**Ce que la skill doit faire, étape par étape** :
[décrivez comme à un nouvel employé :
1. …
2. …
3. …]

**Quand je veux la déclencher** : [ex. quand je dis « fais les relances » ou « prépare l'inventaire »]

**Où sont les données nécessaires** : [ex. export Gestcom déposé dans un dossier, dossier des factures PDF, Outlook]

**Le résultat que je veux** : [ex. un fichier Excel, un mail rédigé mais PAS envoyé, une réponse à l'écran]

**Un exemple concret** : [ce que je demande → ce que je veux obtenir, avec de vraies valeurs]

**Ce que la skill ne doit JAMAIS faire** : [ex. modifier des données dans Gestcom, envoyer un mail sans ma validation, supprimer des fichiers]

Ensuite : crée la skill en français, résume-moi ce qu'elle fera pour que je valide, fais un test avec mon exemple concret, puis propose-la à l'enregistrement (bouton **Save**).

---

## Conseils

- **Une skill = une tâche.** Deux besoins différents → deux skills.
- **Commencez en lecture seule** (consulter, calculer, rédiger). Les actions qui modifient ou envoient quelque chose viendront quand vous aurez confiance.
- **Testez avec un vrai cas** avant de vous en servir au quotidien.
- **Améliorez au fil de l'eau** : si le résultat n'est pas parfait, dites simplement à Claude « modifie la skill pour que… ». Pas besoin de la refaire.
- Vos skills se retrouvent dans **Customize › Skills** : on peut les activer, les désactiver ou les supprimer.
